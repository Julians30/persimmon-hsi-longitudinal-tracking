# Manuscript materials

**Article:** Fruit-Disjoint and Matched-Null Validation of Baseline-Referenced Hyperspectral Models for Tracking Persimmon Storage Time.  
**Journal:** [Foods (MDPI)](https://www.mdpi.com/journal/foods).  
**Status:** Manuscript under review.

Scripts that turn the notebook outputs into the statistics and figures reported in the article.
Run them from this folder (`cd manuscript/scripts`). By default they read the frozen predictions in
`results/manuscript_oof/`; add `--results-root ../../results` to use outputs regenerated by the notebooks.

| Script | Produces | Article |
|---|---|---|
| `primary_contrasts.py` | `tables/primary_contrasts_holm_bonferroni.csv` | Section 2.12; Results 3.6 and 3.7 (C1–C4) |
| `simplification_vs_final.py` | `tables/simplification_vs_final_full.csv` | Section 3.4; Table 5 |
| `make_workflow_figure.py` | `figures/Figure_1.png`, `.pdf` | Figure 1 |
| `make_figures.py` | `figures/Figure_2` to `Figure_9` (`.png`, `.pdf`) | Figures 2–9 |
| `check_ridge_reproduction.py` | console report | Independent re-fit of the notebook 10 Ridge model |
| `colour_index_baseline.py` | `tables/colour_index_baseline.csv`, `colour_index_contrasts.csv`, `colour_index_oof.csv` | Section 2.9; Results 3.4; Table 6 |
| `make_supplement_tables.py` | `tables/supplement/Table_S1.csv`–`Table_S8.csv`, `figures/Figure_S1.png`, `.pdf` | Supplementary Materials (summaries of existing outputs) |

`make_figures.py` (Figures 3 and 7), `colour_index_baseline.py` and `check_ridge_reproduction.py` also need
`data/interim/kaki_fruit_day_spectra_<camera>.csv`, which notebook 01 writes after the raw data have been
downloaded with `python scripts/download_data.py`. The other outputs need only the committed files.

The colour versions of Figures 3 and 7 are committed in PNG and PDF format. The frozen
`tables/colour_index_oof.csv` contains the 2148 out-of-fold predictions underlying the colour-index
comparison (two tasks, three representations and two validation protocols). It can be inspected
without downloading the raw hyperspectral cubes; regenerating it requires the fruit-day spectra.

Figure 6 summarizes the within-sensor and cross-sensor fruit-balanced MAE values of notebook 07 (Table 5),
which are entered in the script with their source noted.

All bootstrap procedures resample physical fruits (5000 resamples, seed 20260818), as in the notebooks.
The independent Ridge re-fit reproduces the archived predictions to within 1e-10 days.
