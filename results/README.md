# Results

Result files generated by the notebooks are ignored by default.

- `reference/`: frozen final-benchmark summary and run manifest of notebook 10.
- `manuscript_oof/`: frozen out-of-fold (OOF) predictions of notebooks 05, 06 and 08–10, stored in the same
  sub-folder names that the notebooks write to. They are the inputs of the scripts in `manuscript/scripts/`, so the
  primary contrasts, Table 5 and Figures 2–9 can be verified without downloading the 2.2 GB raw archive.
